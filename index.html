Faraday Tech – Website Guide

Welcome, Student!

Use Faraday Tech to manage your FARADS, join classroom activities, collect auction items and connect with classmates.

Dashboard buttons – what they do

Profile: edit permitted personal details and privacy settings. FARADS: view your balance and use available transfer controls. School Store: browse items and review purchase receipts. Live Auction: join an invitation and bid while the timer is active.

Bid buttons: each raises the current bid by the displayed amount. Check that you have enough FARADS before bidding. The highest eligible bidder at the end wins.

  1. Profile & FARADS: Update your nickname and profile photo, check your balance, and send FARADS to other accounts when permitted.
  2. School Store & Auctions: Browse shop items, join live auctions, place bids and claim items you win.
  3. Collection & Marketplace: Review your collection and list eligible auction items for sale.
  4. Classes & Video: Open lessons and quizzes, then use the Video Player tab for lesson videos.

Welcome, Teacher!

Use the teacher tools to support students, manage classroom learning and keep the community informed.

Gradebook and assessment setup

Enter student scores in the cells, use Save Worksheet to store them, and use Add Column to add a new assessment. Written includes Summative, Tests, Assignments and Activities; Performance includes Performance Task, Activities and Oral; Exam contains Exam. The existing weight controls determine each category's contribution.

  1. Class & Quizzes: Publish lessons, add reading notes and create quizzes for students.
  2. Gradebook: Review student results, update scores and manage grade columns and weights from Admin & Gradebook.
  3. Auctions & Store: Use the teacher controls to manage live auction activity and classroom shop content where available.

Welcome, Web Developer!

The Developer Console contains the tools for maintaining Faraday Tech and managing platform updates.

Maintenance buttons

Reset Selected Sections: select only the modules to restore. Student accounts, balances, inventories and profiles are intentionally excluded. Run Website Repair Check: checks for malformed local app data and stuck auction timers, then attempts a save and refresh of key views. It cannot fix Supabase permissions, hosting outages or network failures automatically.

  1. Patch Notes: Enter an update name, version number, release date and a clear list of changes, then publish the update.
  2. Account Management: Review accounts, ban or unban accounts, and remove accounts when necessary. Protect your own developer account.
  3. Database: Keep the Supabase project configured with the required app_data fields and Realtime enabled. Never expose a service-role key in this HTML file.
  4. Testing: Test sign-in, registration, profile avatars, marketplace transactions and permissions before publishing changes.

Video Player tab – button guide

Playlist item: select a published video. Play/Pause: start or pause playback. Progress bar: move through the video when supported. If a video does not load, check the video link and browser connection.

Achievements tab – badge guide

Badge cards: review the badges you have earned and any visible progress. Some achievement requirements are intentionally hidden. Rewards, when applicable, are applied by the website.

Other tabs

Class & Quizzes: open lesson notes and complete available quizzes. Directory: select a profile row to view permitted student details. School Store: browse categories, review purchases and access the Collection Marketplace. Profile: review your account details and available privacy controls.
